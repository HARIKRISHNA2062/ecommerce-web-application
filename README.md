# E-Commerce Web Application

## Description
A simple full-stack E-Commerce Web Application developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## Features
- Product Catalog
- Add to Cart
- Checkout
- User Login
- User Registration
- Admin Dashboard
- Product CRUD Operations
- MongoDB Database Integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
